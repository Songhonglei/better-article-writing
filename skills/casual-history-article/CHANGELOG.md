# Changelog

All notable changes to this skill are documented here.
Format loosely follows [Keep a Changelog](https://keepachangelog.com/); versions follow [SemVer](https://semver.org/).

### v1.2.2 (2026-10-13)

- 将百姓家常话明确为默认口吻：随意、休闲、轻松幽默，不靠口头禅、方言模仿或装熟制造亲切感。
- 扩写优先增加真实行动、事情经过、实际困难和后续变化，不靠复述结论或更换类比凑字数。
- 艺术品按背后的人和事组织，避免默认逐件串联博物馆藏品；结尾不转成阅读指导。
- 强化事实与动机的区分，避免由铭文、家书等记录直接补写当事人的心思。
- 明确正文计数口径，排除各级标题、备选标题和文末参考资料；篇幅与引用计数按用户要求执行。
- 合并重复提醒，移除可直接套用的地球布丁例句，保留自然幽默而不规定笑点数量。
- 同步此前仅在本地演进的 v1.2.x 规则：事实与原创增量、去机械表达、核验留在幕后及请求范围。
- 更新使用说明和 Codex 调用提示，保留 MIT 许可证及其他 skill。

### v1.1.0 (2026-07-26)

- 扩充句子与节奏：新增语气控制（缓冲词 / 态度标注 / 主动承认局限，规避教导句）
- 新增手机端排版指南：每段 ≤3 句、每节 300–600 字
- 新增敏感话题「对比结构」句式：同权重呈现多面性，不替读者下结论
- 新增引用轻拿轻放、历史文化题专属写法（真实+虚构人物张力 / 宗教比较 / 误解段三拍）
- 发布前 60 秒检查从 9 条扩到 12 条

### v1.0.0 (2026-07-23)
